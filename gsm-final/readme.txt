Professional GSM Services WordPress Theme with WooCommerce Integration

== Description ==

GSM Ultimate v3.5 FINAL is a professional WordPress theme designed for GSM services businesses.

Features:
* Full WooCommerce integration
* Responsive design (desktop, tablet, mobile)
* Related products grid (3/2/1 columns responsive)
* Multi-language support (English, Vietnamese, Chinese)
* Multi-currency support (USD, VND, CNY)
* Modern 2025 design with CSS variables
* Optimized product layouts
* Mobile-first approach

== Installation ==

1. Download gsm-ultimate-v3-final.zip
2. Go to WordPress Admin > Appearance > Themes > Add New
3. Click "Upload Theme" and choose the ZIP file
4. Click "Install Now"
5. After installation, click "Activate"
6. Clear browser cache (Ctrl+Shift+R)
