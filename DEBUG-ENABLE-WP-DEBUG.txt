# ENABLE WORDPRESS DEBUG MODE

Để xem lỗi cụ thể là gì, bật debug mode:

## Cách 1: Sửa wp-config.php (RECOMMENDED)

1. Mở file: `wp-config.php` (ở thư mục root WordPress)

2. Tìm dòng:
```php
define('WP_DEBUG', false);
```

3. Thay bằng:
```php
define('WP_DEBUG', true);
define('WP_DEBUG_LOG', true);
define('WP_DEBUG_DISPLAY', true);
@ini_set('display_errors', 1);
```

4. Save file

5. Refresh trang web → sẽ hiện lỗi cụ thể thay vì "Đã có một lỗi nghiêm trọng"

6. Chụp màn hình lỗi và gửi cho tôi

---

## Cách 2: Xem error log

Sau khi bật WP_DEBUG_LOG, xem file log:
```
wp-content/debug.log
```

Mở file này và copy 10-20 dòng cuối gửi cho tôi.

---

## Tắt debug mode sau khi xong

Sau khi fix xong, nhớ tắt lại:
```php
define('WP_DEBUG', false);
```
