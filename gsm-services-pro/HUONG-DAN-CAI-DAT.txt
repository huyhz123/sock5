🚀 CÀI ĐẶT THEME (3 BƯỚC ĐƠN GIẢN)

BƯỚC 1: UPLOAD THEME
   1. Đăng nhập WordPress Admin
   2. Vào: Giao diện → Themes → Add New
   3. Click: Upload Theme
   4. Chọn file: gsm-services-pro.zip
   5. Click: Install Now → Activate

BƯỚC 2: CẤU HÌNH MENU
   1. Vào: Giao diện → Menus
   2. Tạo menu mới tên: "Primary Menu"
   3. Thêm trang: Trang chủ, Dịch vụ, Blog, Liên hệ
   4. Chọn vị trí: Primary Menu
   5. Click: Save Menu

BƯỚC 3: THIẾT LẬP TRANG CHỦ
   1. Vào: Settings → Reading
   2. Chọn: A static page
   3. Posts page: Chọn "Blog" hoặc tạo trang mới
   4. Click: Save Changes

✅ HOÀN TẤT! Theme đã sẵn sàng sử dụng!

🔧 GỠ LỖI THƯỜNG GẶP

❓ Menu không hiển thị?
   → Vào Giao diện → Menus → Tạo menu → Gán vào Primary Menu

❓ Dịch vụ mẫu không tạo?
   → Deactivate theme → Activate lại

❓ Nút floating không hiện?
   → Kiểm tra file footer.php có <?php wp_footer(); ?>
   → Xóa cache browser

❓ Muốn xóa dữ liệu mẫu?
   → Vào GSM Services → All Services → Xóa thủ công
   → Vào Posts → All Posts → Xóa bài viết mẫu
