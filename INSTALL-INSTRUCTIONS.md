## 🚀 INSTALLATION STEPS

### **Method 1: WordPress Admin Upload (RECOMMENDED)**

1. **Download the ZIP:**
   - File: `gsm-ultimate-v3.zip` (78KB)

2. **Login to WordPress Admin:**
   - Go to: `yoursite.com/wp-admin`

3. **Navigate to Themes:**
   - Click: **Appearance > Themes**

4. **Upload Theme:**
   - Click: **Add New** button (top)
   - Click: **Upload Theme** button
   - Click: **Choose File**
   - Select: `gsm-ultimate-v3.zip`
   - Click: **Install Now**

5. **Activate:**
   - After installation completes
   - Click: **Activate** button

6. **Clear Cache:**
   - Clear WordPress cache (if using cache plugin)
   - Clear browser cache (Ctrl+Shift+R)

7. **Done!** ✅

## 🐛 TROUBLESHOOTING

### Error: "Giao diện đang bị thiếu style.css stylesheet"

**Solution:**
- Make sure you're uploading `gsm-ultimate-v3.zip` (78KB)
- The ZIP has correct structure with `gsm-ultimate-v3/` folder at root
- style.css is inside the theme folder

### Error: "Destination folder already exists"

**Solution:**
1. Delete old theme folder:
   - Via FTP: Delete `wp-content/themes/gsm-ultimate-v3/`
   - Or rename it to: `gsm-ultimate-v3-old/`
2. Try installation again

### Error: Theme shows but broken

**Solution:**
1. Clear all caches:
   - WordPress cache
   - Browser cache (Ctrl+Shift+R)
   - CDN cache (if using)
2. Check file permissions:
   - Folders: 755
   - Files: 644
3. Re-upload theme

### Search overlay not showing

**Solution:**
1. Clear browser cache
2. Check JavaScript console for errors
3. Make sure Font Awesome is loading (for search icon)
4. Try different browser
